>    - Câu lệnh build debug APK: `./gradlew assembleDebug` (hoặc `gradlew.bat` cho Windows).
>    - Đường dẫn file APK đầu ra: `app/build/outputs/apk/debug/app-debug.apk`.

>    - Lệnh kiểm tra kết nối thành công: `adb devices` (phải hiển thị thiết bị ở trạng thái `device`).
> 5. **Step 3: Install APK onto AAOS Node**:
>    - Lệnh cài đặt đè (reinstall): `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
