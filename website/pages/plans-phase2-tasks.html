Subtask discipline (applies to every subtask below)¶

Per task-planning-conventions.md § Subtask discipline: single objective, no out-of-scope code, exactly one atomic commit with the stated message, build passes, unit tests pass, brief self-contained. Hard execution constraints:

Both operands arrive in the same R2 message, so the sum stays inside one clock domain.
